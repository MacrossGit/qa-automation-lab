# Учебные UI-тесты Sauce Demo

Набор находится в пакете `src/test/java/saucedemo`. Он использует уже подключённые в проекте Java, Maven, Selenium и JUnit 5; новый стек и зависимости не добавляются.

Каждое действие печатает короткое сообщение `[UI]` и делает паузу 2 секунды. После очистки корзины окно остаётся открытым ещё 10 секунд для визуальной проверки. По умолчанию Chrome видим и запускается в режиме инкогнито — это удобно для обучения и изолирует cookies между прогонами. Тесты не переходят к оформлению заказа и не выполняют оплату.

E2E использует новый уникальный адрес на домене `example.com` в каждом прогоне. Если магазин отклонит регистрацию, тест выведет текст ошибки формы.
Если на регистрации появляется CAPTCHA, тест не пытается её обходить и продолжает демонстрацию как неавторизованный покупатель.

## Сценарии

- `AuthenticationTest` — наличие формы входа и обработка неверных данных;
- `CatalogTest` — наличие товаров в общем каталоге и прокрутка на шаг вниз/вверх;
- `CartTest` — отдельное добавление товара и очистка корзины кликами по крестикам позиций;
- `ShopperJourneyE2ETest` — единый путь покупателя: регистрация случайного аккаунта → все карточки → изменение доступных вариантов → корзина → очистка.

## Запуск

```powershell
# Все тесты Sauce Demo
mvn test "-Dtest=AuthenticationTest,CatalogTest,CartTest,ShopperJourneyE2ETest"

# Только учебный E2E-сценарий
mvn test "-Dtest=ShopperJourneyE2ETest"

# Режим CI: браузер без видимого окна
mvn test "-Dtest=AuthenticationTest,CatalogTest,CartTest,ShopperJourneyE2ETest" -Dheadless=true
```

## Почему авторизация проверяется как неуспешная

`https://sauce-demo.myshopify.com/` — Shopify-магазин: его форма входа требует зарегистрированный e-mail и пароль. Данные из задания (`standard_user` / `secret_sauce`) относятся к другому демонстрационному сайту Swag Labs, поэтому на указанном адресе учебный тест проверяет корректный показ ошибки. Для сценария успешной авторизации нужны данные реального тестового аккаунта этого Shopify-магазина либо другой согласованный URL.
